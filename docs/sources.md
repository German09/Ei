# Публикации Инфостарта

[К списку компонентов Ei](../README.md#компоненты-и-источники)

- Библиотека Александра Быкова для управления объектами графической схемы через XDTO. В Ei на неё опирается редактор схем процессов. [Графическая схема. Управление при помощи XDTO](https://infostart.ru/1c/tools/576498/)
- Подход к сериализации и копированию управляемых форм. Ei использует его для наследования форм и учитывает вложенные реквизиты. [Полное копирование одной формы в другую](https://infostart.ru/1c/articles/1119142/)
- Пример запуска внешних команд из 1С с получением вывода и обработкой ошибок. На него ссылается функция `КомандаОкружения` в Ei. [Публикация о запуске приложений из 1С](https://infostart.ru/1c/articles/1266995/)
- Разбор суррогатных пар в UTF-16. По этой публикации реализовано преобразование кодовой позиции Unicode в строку 1С. [1С и Unicode](https://infostart.ru/1c/articles/1720944/)
